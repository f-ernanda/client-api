## 💻 About the project

This project is a simple REST API for managing client records. It implements the main operations of a CRUD (Create, Read, Update, Delete) flow, including pagination and retrieving individual clients.

The API was developed as a backend learning exercise, with a focus on understanding API structure, data persistence, and common backend patterns.

## ✨ Features

The API allows you to:

- List clients with pagination
- Retrieve a client by ID
- Create new clients
- Update existing clients
- Delete clients
